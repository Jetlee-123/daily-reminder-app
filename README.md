# Daily Reminder

Android task reminder app built with Kotlin + Jetpack Compose.

## Setup
See `BUILD_STARTER_GUIDE` from the project chat for full setup steps.

This repo contains Milestone 1: core task CRUD, notifications (recurring/one-off, lead time, quiet hours, vacation mode), search, tags, colours, streaks, dark/light theme.

Milestone 2 (to be added next): quick-add natural language parsing, checklists, notify-mute toggle, cinematic splash screen, home screen widget, app shortcuts.
